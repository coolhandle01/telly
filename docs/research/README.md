A note on provenance, because it matters for how much to trust these: the
cabinet research was done **from written descriptions and search summaries, not
from photographs**, because the environment it was done in blocked most
vintage-set reference sites. Anything in [cabinet.md](cabinet.md) that reads like a
measurement is a reasoned inference, not a measurement, and a real photograph
would beat it.

Where a research finding turned into a rule the code must follow, the rule is
restated in [architecture/](../architecture/) and that is the authoritative
copy.
